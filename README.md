# Cosmoproff — демо интернет-магазина

Демо-сайт магазина профессиональной уходовой косметики. Без базы данных и сервера:
обычные HTML / CSS / JS, можно открыть `index.html` двойным кликом или выложить на GitHub Pages.

## Что есть на сайте
- шапка с каталогом, городом доставки, поиском, избранным, профилем и корзиной;
- слайдер-баннер, круглые «истории», полки «хиты», «новинки», «для кабинета косметолога»;
- каталог с фильтрами по категориям и брендам, сортировкой и «показать ещё»;
- карточка товара: объёмы, количество, описание / применение / состав, «с этим покупают»;
- корзина: бесплатная доставка от 15 000 ₸, промокоды `PINK20` (−20%, кроме наборов) и `COSMO10` (−10%), оформление заказа;
- тест «подбор ухода» (тип кожи → задача → время) собирает ритуал из каталога;
- Cosmoproff Club (вход по телефону, любой код из 4 цифр), заявка для косметологов, журнал, подписка;
- мобильная версия с нижним меню, как в приложениях магазинов.

Корзина, избранное, город и «аккаунт» хранятся только в браузере (localStorage). Формы никуда не отправляются.

## Как поменять товары
Все бренды, товары, цены, истории и статьи — в `js/data.js`.
Картинки товаров рисуются кодом (`js/art.js`) по полю `shape`
(`dropper`, `pump`, `tube`, `jar`, `spray`, `bottle`, `set`, `card`) и цветам `c` (флакон) и `c2` (крышка),
поэтому фото не нужны. Бренды и товары в демо условные.

После правок увеличьте `?v=...` у файлов в `index.html`, чтобы браузеры подхватили новую версию.
